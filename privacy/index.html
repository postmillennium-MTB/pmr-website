Privacy Policy

Last updated August 10, 2026

Post Millennium Renaissance is a personal site, not a company collecting data to sell. There are no accounts, no mailing list, and no contact form here. This page plainly covers the small amount of information the site does touch — and it's written to describe exactly what this site actually does, not a generic template.

What this site doesn't do

  • No user accounts or logins
  • No email collection or newsletter signup
  • No contact or lead-generation forms
  • No advertising trackers or retargeting pixels
  • Your information is never sold to anyone

Saved in your browser

A couple of small preferences — which color theme you're viewing the site in, and the order you've dragged the tool cards into on the homepage — are saved using your browser's local storage. That stays on your device. It's never sent to a server, and I never see it.

Site analytics

This site does not currently run any visitor analytics or tracking. If that changes — for example, if Google Analytics is added later to understand which tools get used — this page will be updated first to describe it.

The interactive tools

Some of the tools on this site — the Wheel Strength Lab, the Suspension Lab, and others — load their interactive content from postmillennium-mtb.github.io, a companion domain also run by Post Millennium Renaissance, used only because of how those tools are hosted. They don't collect anything beyond what's already described on this page.

The sticker shop

If you buy a sticker, checkout happens entirely on Stripe's own secure payment page — not on this site. Card details are never seen or stored here. Stripe shares the order information needed to fulfill and ship your order — name, shipping address, and email — with me. Stripe's handling of your information is covered by Stripe's own privacy policy.

Changes to this page

If what this site collects, or how it's used, ever changes, this page will be updated to reflect that.

Questions

Reach out any time at jon@pmr.bike.

This page is written in plain English to be genuinely accurate to what this site does — it isn't legal advice, and it isn't a substitute for a lawyer's review.
