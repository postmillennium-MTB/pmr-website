Conformance status

This site targets the Web Content Accessibility Guidelines (WCAG) 2.1, Level AA. We test against it with automated tooling (axe-core) across every page and every seasonal theme — Day, Spring, Autumn, Winter, and 2049.

As of August 10, 2026, that automated testing passes across the site: no missing text alternatives, no label, heading-order, or ARIA issues, and no color-contrast failures — including a round of fixes that brought all five themes' text and button colors up to the required 4.5:1 ratio. One page, the stickers gallery, still has a known, unresolved contrast issue.

Automated testing verifies a meaningful slice of WCAG — contrast, semantics, labels, structure — but not everything the standard covers. We haven't yet completed a full manual pass (keyboard-only navigation, screen reader testing) on the site's interactive tools, so our status is automated AA testing passing, manual verification in progress, rather than a complete AA conformance claim.

Measures we've taken

  • Automated WCAG 2.1 A/AA scanning across all pages and themes, with issues found and fixed
  • Semantic HTML structure and landmark regions
  • Text alternatives for meaningful images
  • Color contrast verified at 4.5:1 or better across all five themes
  • Keyboard-navigable interface elements
  • Responsive layouts that support zoom and reflow

Known limitations

Stickers page

A color-contrast issue affecting ledger and pricing text has been identified and is not yet fixed.

Interactive tools

The wheel visualizer, patent-stack browser, tire simulator, and comparison widgets haven't yet had a manual keyboard-navigation or screen-reader pass. Automated testing found no issues on them, but that doesn't guarantee they're fully usable that way — we're working through this.
